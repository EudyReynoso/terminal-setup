# PowerShell

`Microsoft.PowerShell_profile.ps1` es el perfil que uso. Configura Oh My Posh (tema Eclipse), Terminal-Icons, PSReadLine, zoxide y funciones para eza, bat y Git.

## Requisitos

PowerShell 7 (`pwsh`), Oh My Posh, Terminal-Icons, PSReadLine, zoxide, eza, bat y Git. El perfil llama a esos programas; instálalos antes de iniciar una sesión.

## Instalar

Desde la raíz del repositorio, ejecuta `./scripts/install.ps1`. El script crea las carpetas requeridas y respalda el perfil anterior con una marca de tiempo.
