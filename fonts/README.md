# Fuentes

Las fuentes no se guardan en este repositorio. Instálalas por separado en Windows para que los símbolos del prompt y los glifos Nerd Font se vean correctamente.

## Familias que usa mi configuración

- **Monaspace Argon NF SemiBold**: fuente predeterminada de Windows Terminal.
- **Monaspace Neon NF**: perfil PowerShell de Windows Terminal.
- **CaskaydiaCove NF**: terminal de Tabby (configuración `CaskaydiaCove NF`).
- **Nerd Font compatible**: Oh My Posh usa iconos de Nerd Font en su tema Eclipse.

Después de instalar una fuente, cierra y vuelve a abrir las aplicaciones de terminal. Los archivos de ajustes guardan el nombre de familia, no la fuente misma.
