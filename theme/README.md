# Temas y colores

- **Oh My Posh**: tema personalizado Eclipse en `../oh-my-posh/themes/eclipse.omp.json`.
- **Tabby**: esquema oscuro integrado `Tabby Default`, definido en `../tabbyconfig/config.yaml`.
- **Windows Terminal**: esquema integrado `Dark+`, seleccionado por el perfil PowerShell en `../windows-terminal/settings.json`.

Windows Terminal usa `Monaspace Argon NF SemiBold` como fuente predeterminada y `Monaspace Neon NF` en PowerShell. Tabby usa `CaskaydiaCove NF`.
