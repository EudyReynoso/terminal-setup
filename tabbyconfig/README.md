# Tabby

`config.yaml` es una copia de la configuración de Tabby de este equipo. Incluye atajos, apariencia, terminal, fuente CaskaydiaCove NF y opciones generales.

Para instalarla, cierra Tabby, respalda `%APPDATA%\tabby\config.yaml` y copia este archivo a esa ruta. Al iniciar, Tabby leerá la configuración. Esta exportación no lleva perfiles ni almacén de credenciales guardados.
