# Windows Terminal

`settings.json` es la copia completa de los ajustes actuales de Windows Terminal. Define PowerShell 7 como perfil predeterminado, el esquema integrado `Dark+` y Monaspace Argon/Neon NF con ligaduras.

Para restaurarla, abre Windows Terminal → Configuración → Abrir archivo JSON. Cierra la aplicación y respalda el archivo de ajustes actual antes de sustituirlo por esta copia. La copia completa incluye los perfiles integrados de Windows PowerShell, Símbolo del sistema y Azure Cloud Shell.
