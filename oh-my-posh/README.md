# Oh My Posh

El tema personalizado está en [`themes/eclipse.omp.json`](themes/eclipse.omp.json). El perfil de PowerShell carga el archivo desde `$HOME/.config/ohmyposh/mythemes/eclipse.omp.json`; el instalador copia el tema a esa ubicación.

Requisitos: Oh My Posh y una fuente Nerd Font compatible. El tema muestra directorio, usuario, rama y estado de Git, hora y estado del último comando.
